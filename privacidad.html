Política de privacidad

Última actualización: 28 de octubre de 2026

1. Qué es esta herramienta

"elarchivocurioso scripts" es una herramienta de uso privado que utiliza la persona responsable del canal de YouTube El Archivo Curioso para gestionar su propio canal: subir sus vídeos, completar títulos, descripciones, miniaturas, subtítulos y listas de reproducción, y consultar las estadísticas y los comentarios del canal. No es una aplicación pública ni está pensada para que la usen otras personas.

2. Qué datos se usan

Con el permiso que concede la persona titular de la cuenta, la herramienta accede a través de la API de YouTube a:

  • La información del canal (nombre, descripción, imagen y estadísticas).
  • Los vídeos, listas de reproducción y subtítulos del canal.
  • Los comentarios públicos recibidos en el canal, solo para leerlos.

3. Cómo se guardan

  • El permiso de acceso se guarda únicamente en el ordenador de la persona titular, en el gestor de credenciales del sistema.
  • Los datos se usan solo para gestionar el propio canal. No se venden, no se comparten con terceros y no se usan para publicidad.
  • La herramienta no recopila datos de los espectadores del canal.

4. Esta web

Esta web no usa cookies propias ni formularios. Los vídeos se muestran con el reproductor de YouTube en modo de privacidad mejorada (youtube-nocookie.com); al reproducirlos se aplica la política de privacidad de Google.

5. Servicios de Google

La herramienta usa los Servicios de la API de YouTube. Al ver el canal también se aplican las Condiciones del Servicio de YouTube y la Política de Privacidad de Google.

El uso de la información recibida de las API de Google cumple la Política de Datos de Usuario de los Servicios de las API de Google, incluidos los requisitos de uso limitado.

6. Cómo retirar el acceso

El acceso puede retirarse en cualquier momento desde myaccount.google.com/permissions.

7. Contacto

Para cualquier consulta sobre esta política, puedes escribir a través del canal de YouTube.
